# Architecture Decision Records
# ─────────────────────────────────────────────
# This directory contains all architectural decisions made in this project.
# Each decision is recorded as an ADR (Architecture Decision Record).
#
# Rules:
# - Never delete an ADR — mark it as superseded instead
# - Every superseded ADR must reference its replacement
# - New ADRs are proposed by the analysis agent, accepted by the human
# - ADR numbering is sequential and never reused

## Index

ADR-001  accepted  Layered monorepo structure
ADR-002  accepted  Hexagonal architecture for backend
ADR-003  accepted  httpOnly cookie for JWT authentication
ADR-004  accepted  docs/contracts as single source of truth
ADR-005  accepted  Per-layer sprint management

# Status legend:
# proposed    → under discussion, not yet implemented
# accepted    → implemented and active
# rejected    → evaluated and discarded (kept for reference)
# superseded  → replaced by a newer ADR (see superseded_by field)
